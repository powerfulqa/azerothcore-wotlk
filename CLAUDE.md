## This fork: classless roguelite server project

This fork carries an original, non-commercial game-design project on top of upstream
AzerothCore. Before starting any task on it, read **`docs/WORKING_AGREEMENT.md`** — it
defines the RPAC workflow, the approval gates and the non-negotiable rules that govern
work here. Then `docs/README.md` for the document map, and `docs/DECISION_LOG.md` for
what has been decided and what the next action is.

Upstream's rules in `AGENTS.md` and `.agents/docs/` still apply in full.
